🚨 Women Safety System

📖 About the Project

The Women Safety System is a web-based application developed to improve women's safety and security through technology. It provides a platform where users can register, log in, access a dashboard, and use emergency safety features.

The main goal of this project is to provide a simple, user-friendly and accessible safety solution that helps women respond to emergency situations.

🎯 Objectives

- To develop a technology-based solution for women's safety.
- To provide a quick emergency alert mechanism.
- To allow users to manage emergency contacts.
- To provide secure user registration and login.
- To create an easy-to-use safety dashboard.
- To promote awareness and accessibility of digital safety solutions.

🚀 Key Features

1. User Registration

- New users can create an account.
- User details are stored in the database.

2. User Login

- Registered users can log in.
- User authentication provides access to the dashboard.

3. Dashboard

- Provides a centralized interface.
- Allows users to access safety-related features.

4. Emergency Alert System

- Provides an emergency alert option.
- Designed to help users request assistance during dangerous situations.

5. Emergency Contact Management

- Allows users to manage emergency contact information.
- Helps users keep important contact details accessible.

🔄 Working Process

1. The user opens the Women Safety System.
2. A new user registers using the registration page.
3. The registered user logs in.
4. The system redirects the user to the dashboard.
5. The user accesses the available safety features.
6. The user can use the emergency alert feature when assistance is required.
